## English Entry

For presentation preparation, start with the **[bilingual learning hub](course_project_mh6805/docs/LEARNING_HUB.md)**: ML concepts, quantitative-finance foundations, terminology and 23 Q&A prompts.

This is the dedicated MH6805 Group 12 course repository. Start with the [detailed English README](course_project_mh6805/README.md) for objectives, temporal design, four models, results, environment and complete commands. The [bilingual classmate guide](course_project_mh6805/docs/CLASSMATE_GUIDE.md) explains how to navigate the project.

The course compares Logistic Regression, Random Forest, XGBoost and LightGBM using historical CSI 500 membership, announcement-based fundamentals, purged temporal model selection and transaction-cost-aware daily portfolio evaluation. Reports and aggregate results are public; licensed inputs and stock-level model artifacts are not. Inspecting saved evidence is not a new empirical run. See the detailed README for reproduction prerequisites and limitations.

The course package is in `course_project_mh6805/`; the legacy internship project remains in its original separate repository. This repository does not upload data, send messages or start scheduled jobs automatically.
